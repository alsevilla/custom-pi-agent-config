# Design Critique

## Framework

1. **First Impression (2 seconds)**, What draws the eye? Is purpose clear?
2. **Usability**, Can user accomplish goal? Navigation intuitive?
3. **Visual Hierarchy**, Reading order, emphasis, whitespace
4. **Consistency**, Design system adherence
5. **Accessibility**, Contrast, touch targets, readability

## How to Give Feedback

- Be specific: "The CTA competes with nav" not "layout confusing"
- Explain why: link to design principles
- Suggest alternatives
- Acknowledge what works
- Match the stage: exploration is not final polish

## Output

Markdown table with Finding / Severity / Recommendation, plus Priority Recommendations section.
